# Geometry_util
This package, designed for nanoparticle studies, includes the calculation of useful structural and morphological descriptors, as well as functions for structural modifications intended for computational studies. These features are considered important for the interpretation of experimental spectral measurements. The figure below illustrates the descriptors that have been calculated.
